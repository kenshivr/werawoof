# Marca

- `logo-horizontal.png`, `logo-huella.png`: logos en alta resolución con fondo transparente.
- `firma-correo.html`: firma de correo de marca. Ábrela en el navegador, selecciona todo, copia y pega en
  Gmail → Configuración → Firma. Con `?preview=1` usa el logo local en vez del publicado.

El material de redes (piezas, plantillas, calendario y fotos) se gestiona fuera de este repositorio.
